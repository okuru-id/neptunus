# Neptunus v0.2.24

A fix-up release for [v0.2.23](https://github.com/okuru-id/neptunus/releases/tag/v0.2.23): same features, and the iOS build works again.

## Fixed

- **iOS:** the IPA builds again. The lock screen player's MediaPlayer framework is now linked into the app, which broke the v0.2.23 iOS build.

## New since v0.2.22

If you're coming from v0.2.22, this is the first release with the full video update on every platform:

- 🎬 **Video menu** with Ekstensi, Lokal and Cloud S3 tabs; Stremio addon catalogs (Cinemeta by default, anime included), title pages with seasons and episode cards, and a source picker across all addons.
- ▶️ **New player** with YouTube-style controls, subtitles from Stremio subtitle addons (language, delay, size, colour, background, position), HLS support and an Open in VLC button.
- 💾 **Cached in the local database:** catalogs, sources and subtitles open instantly and keep working when an addon is down.
- ⬆️ **In-app updates:** download and install the new version, or any release file, without opening a browser. iOS shows how many days the signature has left.

See the [v0.2.23 notes](https://github.com/okuru-id/neptunus/releases/tag/v0.2.23) for the full list.

## Install

| Platform | File |
|---|---|
| Linux | `.deb`, `.rpm` or `.AppImage` |
| Windows | `-setup.exe` or `.msi` |
| macOS | `_aarch64.dmg` (Apple Silicon) or `_x64.dmg` (Intel) |
| Android 8.0+ | `_arm64.apk` |
| iOS | `_unsigned.ipa`, sign it with SideStore, iloader or LiveContainer |

Updating from v0.2.22 has to be done manually once. From v0.2.23 on, use **Unduh & pasang** in the update banner or Settings › Tentang.
