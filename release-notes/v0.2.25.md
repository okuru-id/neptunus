# Neptunus v0.2.25

Streams that played on the desktop now play on Android and iOS too, and films with several audio tracks let you pick the dub.

## New

- 🔊 **Audio track picker.** When a video has more than one audio track (dubs, commentary), the CC panel gets an **Audio** section to switch between them. It works for HLS streams and for files the system player exposes tracks for.
- 🔢 **Numbered lists.** Songs in a playlist (including ones not downloaded yet) and the files in the source picker are numbered.

## Fixed

- **Android:** streams over plain `http://` (local servers, many debrid links) failed with *error 4: MEDIA_ELEMENT_ERROR: format error* in release builds. They are allowed now.
- **iOS:** the same `http://` streams were blocked by App Transport Security and are allowed now.

## Notes

- If a stream still fails on a phone with *error 4*, the file itself is in a format the phone's player can't decode (MKV, HEVC, AC3/DTS audio). Desktop plays these through GStreamer; on a phone use VLC.
- Android's WebView doesn't report a file's audio tracks, so the Audio picker may not show there for MKV/MP4 files; HLS streams with several audio tracks do work.

## Install

| Platform | File |
|---|---|
| Linux | `.deb`, `.rpm` or `.AppImage` |
| Windows | `-setup.exe` or `.msi` |
| macOS | `_aarch64.dmg` (Apple Silicon) or `_x64.dmg` (Intel) |
| Android 8.0+ | `_arm64.apk` |
| iOS | `_unsigned.ipa`, sign it with SideStore, iloader or LiveContainer |

From v0.2.23 on, update with **Unduh & pasang** in the update banner or Settings › Tentang.
