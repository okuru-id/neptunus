# Neptunus v0.3.9

iOS opens and plays films again, and films the computer app repairs start more reliably.

## Fixed

- 🍎 **iOS no longer closes at launch.** The VLC engine the film player is built on is now part of the app, and the app no longer uses VLC's clock in place of the system's, which made it stop as soon as it opened.
- 🤖 **Android films with subtitles start.** Films with the extensions' subtitles failed to start in the Android player; they play now, subtitles shown.
- 👆 **iOS player controls come back with a tap.** Once hidden, the controls (play, seek, subtitle, audio, close) never returned; a tap on the picture shows them again.

## Changed

- 🛠️ **Repaired films start more reliably.** The film's host gets the same headers when the app repairs a film with ffmpeg, a first try that takes too long is tried once more (by then part of the film is already on disk), and ffmpeg runs at a lower priority so the app stays smooth while it works.

## Install

| Platform | File |
|---|---|
| Linux | `.deb`, `.rpm` or `.AppImage` (mpv and ffmpeg recommended) |
| Windows | `-setup.exe` or `.msi` |
| macOS | `_aarch64.dmg` (Apple Silicon) or `_x64.dmg` (Intel) |
| Android 8.0+ | `_arm64.apk` |
| iOS | `.ipa` (OTA when available) or `_unsigned.ipa`, sign it with SideStore, iloader or LiveContainer |

Update with **Unduh & pasang** in the update banner or Settings › Tentang.
