# Neptunus v0.3.8

The iOS build that v0.3.7 was missing, and dubs to pick in films the app repairs.

## Fixed

- 🍎 **iOS is back.** v0.3.7 couldn't be built for iOS; this release has it, with films playing in VLC's engine (MKV, HEVC, AC3/DTS, the extensions' subtitles) instead of the WebView. Everything else is as in v0.3.7.
- 🗣️ **Dubbing in repaired films.** Films the app player repairs with ffmpeg kept only their first audio track; now every track comes along and can be picked under **Audio & subtitle**, named by its title or language.

## Install

| Platform | File |
|---|---|
| Linux | `.deb`, `.rpm` or `.AppImage` (mpv and ffmpeg recommended) |
| Windows | `-setup.exe` or `.msi` |
| macOS | `_aarch64.dmg` (Apple Silicon) or `_x64.dmg` (Intel) |
| Android 8.0+ | `_arm64.apk` |
| iOS | `.ipa` (OTA when available) or `_unsigned.ipa`, sign it with SideStore, iloader or LiveContainer |

Update with **Unduh & pasang** in the update banner or Settings › Tentang.
