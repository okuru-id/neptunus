# Neptunus v0.2.26

Videos go properly fullscreen on phones, subtitles included, and Linux updates install from a terminal.

## Fixed

- 📱 **Fullscreen on Android.** The fullscreen button did nothing in the Android app. It now hides the status and navigation bars and turns the screen to landscape; swipe from the edge to bring the bars back for a moment. Leaving fullscreen or closing the player restores both.
- 📱 **Fullscreen on iPhone.** The fullscreen button now opens the iOS video player, which rotates with the device.
- 💬 **Subtitles in fullscreen.** On Android the subtitle overlay stays on screen with your size, colour, background, position and delay. On iOS the chosen subtitle is passed to the system player, with your delay applied.

## Changed

- 🐧 **Linux updates install in a terminal.** **Unduh & pasang** no longer hands the `.deb`/`.rpm` to the software center. It opens a terminal that runs `sudo apt install` (or `dnf`, `zypper`, `rpm` for `.rpm`), asks for your password there, and waits for Enter so you can read the result. Without a terminal, the file opens as before. AppImage updates still open their folder.

## Notes

- **iOS:** in fullscreen, subtitles follow the system caption style (Settings › Accessibility › Subtitles & Captioning), not the style in the CC panel. Pick the subtitle before going fullscreen; it can't be changed there.

## Install

| Platform | File |
|---|---|
| Linux | `.deb`, `.rpm` or `.AppImage` |
| Windows | `-setup.exe` or `.msi` |
| macOS | `_aarch64.dmg` (Apple Silicon) or `_x64.dmg` (Intel) |
| Android 8.0+ | `_arm64.apk` |
| iOS | `_unsigned.ipa`, sign it with SideStore, iloader or LiveContainer |

From v0.2.23 on, update with **Unduh & pasang** in the update banner or Settings › Tentang.
