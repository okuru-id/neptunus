# Neptunus v0.2.23

Neptunus is now a music **and video** player. This release adds a full video section, a subtitle-ready player, and updates that install from inside the app.

## 🎬 Video

- **New Video menu** with three tabs: **Ekstensi**, **Lokal** and **Cloud S3**. Videos (MP4, MKV, WebM, MOV) from your music folders and your S3 bucket show up automatically.
- **Stremio addons.** Paste any Stremio addon manifest URL in Settings › Ekstensi › Video. Catalogs appear as horizontal rows (Cinemeta is added by default), including anime and other catalog types.
- **Title pages** with the artwork as a full background, a season dropdown and episodes as a card strip. Series that an addon lists without episodes get their episode list from another addon or TVmaze.
- **Source picker** that lists every addon's streams side by side, one tab per addon, with quality, size, codec and release tags. Each tab says why it is empty (no sources, torrent only, or an error).
- **Per-extension switches** for Katalog, Sumber film and Subtitle, so each addon is used only for what you want.
- **Faster and offline-friendly.** Catalogs, details, sources and subtitle lists are kept in the local database, so pages open instantly and still work when an addon is down. **Muat ulang** buttons fetch fresh data.
- Sticky tabs with the back and reload buttons beside them, and the page you were on survives a reload.

## ▶️ Player

- **YouTube-style controls:** red seek bar with buffered range and time preview, skip ±10 s, volume, fullscreen, auto-hiding bar, keyboard shortcuts (Space/K, ←/→, F, M, C).
- **Subtitles** from Stremio subtitle addons, in a side panel: pick the language (shown with the addon name), adjust the delay (G/H), and set size, colour, background and position with a live preview. Style, per-video delay, the chosen subtitle and the subtitle files are saved in the database.
- Plays through the system media stack (GStreamer, WebKit, Android) for the widest codec support, with hls.js only as an HLS fallback. Resumes where you left off.
- **Open in VLC** for anything the system can't decode.

## ⬆️ Updates

- **Download & install from the app.** The update banner and Settings › Tentang fetch the right installer for your system into Downloads and open it. Android and iOS hand the APK/IPA to the browser.
- **All releases in the app.** Settings › Tentang › Semua rilis lists every release and its files, each downloadable without opening a browser.
- **iOS:** Settings › Tentang shows how many days the current signature has left.

## Other

- Extension settings split into **Musik** and **Video**; music extensions (SpotiFLAC format) come from one merged repository list with install and update buttons.
- In-app dropdowns that follow the app theme.
- The license (MIT) is now included and viewable in Settings › Tentang.
- README rewritten.

## Notes

- **Linux:** video needs `gstreamer1.0-plugins-good`, `gstreamer1.0-plugins-bad` and `gstreamer1.0-libav` (the `.deb` installs them).
- **iOS:** the IPA failed to build for this version. Use the IPA from **v0.2.24**, which contains the same features plus the build fix.
- Updating from v0.2.22 has to be done manually once; in-app updates work from this version on.
- Neptunus ships no media and no streaming sources; you choose which addons to install.
