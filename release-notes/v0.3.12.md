# Neptunus v0.3.12

A catalog song plays on the first tap, and the Linux media notification shows the cover.

## Fixed

- ▶️ **Catalog songs stream on the first tap.** Tapping a song in the catalog did nothing until another song had been played; it now streams straight away.
- 🐧 **Cover art in the Linux media notification.** The MPRIS notification and media widgets show the playing song's cover, also when it is found online after the song starts.

## Install

| Platform | File |
|---|---|
| Linux | `.deb`, `.rpm` or `.AppImage` (mpv and ffmpeg recommended) |
| Windows | `-setup.exe` or `.msi` |
| macOS | `_aarch64.dmg` (Apple Silicon) or `_x64.dmg` (Intel) |
| Android 8.0+ | `_arm64.apk` |
| iOS | `.ipa` (OTA when available) or `_unsigned.ipa`, sign it with SideStore, iloader or LiveContainer |

Update with **Unduh & pasang** in the update banner or Settings › Tentang.
